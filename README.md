# L'hai mai chiesto? · laboratorio

Strumento per l'incontro su social, chatbot IA e affettività del ciclo
**Lazzaretto Hospes 2026-2027 · «Lo hai mai fatto? Parliamo d'amore»**.

**Pagina:** https://antori.github.io/hai-mai-chiesto/

I gruppi progettano dal telefono un piccolo gioco che trasmette un loro messaggio,
seguendo il metodo *messaggio → meccaniche → narrativa*. Il gioco gira nel browser
con il motore [LÖVE](https://love2d.org) compilato in WebAssembly (love.js).
«L'hai mai chiesto?» è l'esempio svolto: serve per capire come funziona il kit,
non è il gioco da consegnare.

## Cosa c'è qui

| | |
|---|---|
| `index.html` | la pagina del laboratorio: Progetta · Gioca · Condividi · Codice |
| `game-love.html`, `engine/` | il gioco nel browser (love.js 11.4.1, licenza MIT) |
| `gioco/` | lo stesso gioco per LÖVE 11.5 sul computer: `love gioco` |
| `LEGGIMI.txt` | istruzioni per ospitare la pagina altrove e struttura del kit |

Il lavoro di ogni gruppo resta nel browser del telefono: per conservarlo o
mostrarlo sul proiettore si usa la scheda «Condividi».

## Stato

Versione di lavoro, non ancora provata con una classe. I numeri di aiuto nella
schermata finale e le domande di cura vanno confermati dai clinici e dagli
psicologi del ciclo prima dell'uso con gli studenti.
