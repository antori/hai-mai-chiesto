design.lua

Questo è il vostro gioco scritto in Lua, la lingua di LÖVE. «Progetta» scrive questo file per voi; qui potete modificarlo direttamente.

  • Ogni elemento finisce con una virgola: chi = "Sami",
  • Le frasi stanno tra virgolette dritte "…"; dentro usate «» per le citazioni.
  • Effetti: like + 10, coraggio - 1, umore = 0 · Condizioni: like > 50 e coraggio >= 1
  • Le righe che iniziano con -- sono commenti: il gioco le ignora. Le emoji non si vedono nel gioco: vengono tolte.
